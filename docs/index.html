Cashu Book of NUTs

compiled by Adam Shannon

The Cashu Notation, Usage, and Terminology documents, grouped by theme and bound as a book. The NUT text is unchanged from the community repository; the reading order and chapter introductions are new.

Start with the core protocol if you are new. Later chapters are optional.
